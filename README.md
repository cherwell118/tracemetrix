# Files explanation
## Data 
1. The case study 1 data in the article is sourced from the literature: Wan L, Liu Q, Liang D, Guo Y, Liu G, Ren J, He Y, and Shan B (2021) Circulating Tumor Cell and Metabolites as Novel Biomarkers for Early-Stage Lung Cancer Diagnosis. Front. Oncol. 11:630672. doi: 10.3389/fonc.2021.630672IF.The
        
        
        
         data is derived from early-stage lung cancer samples, which include 30 cancer samples, 30 healthy individual samples, and 8 QC (Quality Control) samples. Each type of sample contains both positive and negative modes. All data including MS/MS informations.
2. The case study 2 data in the article is sourced from the literature(MTBLS2627): Liu W, Wang Q, Chang J, Bhetuwal A, Bhattarai N and Ni X (2022) Circulatory Metabolomics Reveals the Association of the Metabolites With Clinical Features in the Patients With Intrahepatic Cholestasis of Pregnancy. Front. Physiol. doi: 10.3389/fphys.2022.848508.The
        
        
        
         data is derived from Intrahepatic cholestasis of pregnancy(ICP) samples, which include 52 case samples, 57 healthy individual samples. Each type of sample contains both positive and negative modes. All data including MS/MS informations.
3. Due to the upload limitations on GitHub, the case study 1 files have been compressed using 7z and segmented, and the case study 2 could found in the MetaboLights(MTBLS2627).
   
## R code
1. R function contains the underlying R code for all analytical functions in TraceMatrix.
2. R packge including some R functions were used in analytical functions
